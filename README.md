# Level 3 Project 2

## Project Description

This project collects Machine Learning repository data from the GitHub API, prepares and cleans the data, stores it in SQLite, and performs SQL analysis and Python visualizations.

## Tasks

### Task 1 – Data Collection & Preparation
- Retrieve repository data from GitHub API
- Convert JSON data into a Pandas DataFrame
- Clean and prepare the dataset
- Save the cleaned dataset as github_projects.csv

### Task 2 – Store & Analyse the Data
- Store the dataset in SQLite
- Perform SQL analysis
- Create Python visualizations
- Interpret the results

### Task 3 – Git & GitHub
- Initialize a Git repository
- Stage and commit the project files
- Publish the project on GitHub
- Provide project evidence
- Complete the ethics reflection
